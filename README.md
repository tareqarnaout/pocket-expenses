# Pocket Expenses

Pocket Expenses is an Android household budget app for tracking expenses, income, transfers, savings, upcoming bills, financial reports, SMS transaction review, home-screen widgets, and biometric app unlock.

## Download

Install the latest signed APK from the [Releases](../../releases/latest) page.

Android package: `com.householdledger.expenses`

## Updates and authenticity

Every update is signed with the same Pocket Expenses signing certificate. Install future versions from this repository to receive compatible upgrades.

## Privacy

Financial data is stored in the Supabase project configured in the app. Users can configure their own Supabase server. Device features such as SMS review and biometric unlock remain under Android permission controls.

## Source availability

This repository distributes compiled application releases and listing information. The application source code and signing material are not published here.
